# W.01 – JavaScript Beginner Project: Student Welcome Portal

## Project Overview

Create a simple and attractive web page that welcomes a new student to a learning platform. Your project should use **HTML** for the structure, **CSS** for styling, and **JavaScript** for user interaction.

This project will help you practice connecting HTML, CSS, and JavaScript while building your first interactive webpage.

---

# Project Requirements

## Part 1 – HTML

Create a webpage that includes:

* A main heading (e.g., **Student Welcome Portal**)
* A short description of the website
* A **Start Registration** button
* An area where messages can be displayed after the user enters their information

---

## Part 2 – CSS

Style your webpage by:

* Centering the content on the page
* Adding a background color or gradient
* Using readable fonts
* Styling the button with hover effects
* Adding padding, margins, and rounded corners
* Creating a clean and modern layout

---

## Part 3 – JavaScript

When the user clicks the **Start Registration** button:

### Step 1

Ask the user for:

* Full Name
* Age
* Country
* Favorite Programming Language

Store each answer in a variable.

---

### Step 2

Display a personalized welcome message on the webpage.

Example:

> 👋 Welcome, Sarah Ahmed!
>
> We are excited to have a 19-year-old student from Kenya.
>
> Your favorite programming language is JavaScript.
>
> We hope you enjoy your learning journey!

---

### Step 3

Display all the collected information in the browser and in console.

Example:

```text
===== Student Information =====
Name: Sarah Ahmed
Age: 19
Country: Kenya
Favorite Language: JavaScript
===============================
```
